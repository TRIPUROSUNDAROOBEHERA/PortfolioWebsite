# Developer Portfolio & Management Terminal

An end-to-end full-stack portfolio and administration web application built with **React 18**, **Tailwind CSS**, and a **Django REST Framework** backend.

## 🚀 Key Features

* **Terminal UI & Visitor View**: Interactive overview featuring direct message transmission, dynamic projects catalog, certification showcase, education history, and developer resources.
* **Secured Admin Terminal**: Full CRUD control dashboard for editing experience entries, managing project portfolios, modifying skill sets, and reading incoming messages.
* **Authentication & Security**: Protected JWT token routing, automated token refresh logic, and protected API clients.
* **Comprehensive Test Suite**: 100% test coverage using **Vitest** and **React Testing Library** for API services, custom UI components, and application routes.
